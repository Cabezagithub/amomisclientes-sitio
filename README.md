# Proyecto AmoMisClientes - Sistema de ventas

Objetivo: desarrollar un sistema de venta completo automatizado para AmoMisClientes que permita:
1- Interactuar con Google Maps para buscar negocios por ciudades
2- Interactuar con Google ADS para promocionar AmoMisClientes
3- Interactuar con Meta para posicionar en Instagram AmoMisClientes

## Herramientas a desarrollar

### Sitio web completo de ventas que permita mantener fuertemente SEO para Google

## Características que hay que tener en cuenta

- El objetivo es comercializar el sistema en todo el mundo, por lo tanto el sitio debe ser con etiquetas para multilenguaje
- Respecto de la edición: no vamos a tener edición constante del material, sino a lo sumo de las etiquetas para ventas
- Vamos a acpetar pagos por Stripe y en Argentina por Mercado Pago

## Atención por medio de IA

### Atención por medio de: PBO-AssistantIA

- Vamos a atender por diferentes canales por medio de PBO-AssistantIA. Canales:
    . Whatsapp
    . Chat propio que debe insertarse en el sitio
    . Telegram
